# 陕建外聘人员考勤工资核算

## 目标

使用三类带角色附件完成可追溯的工资核算：

- `roster`：人员底表，人员身份、项目和人员类别来源；
- `historical_payroll`：历史人工工资表，提取固定工资构成、月份公共规则和同月对比参考；
- `attendance`：当月签字考勤资料，识别实际出勤和请假信息。

工资规则是本 Skill 的固定内置规则，不要求用户上传规则文件。不得把模型估算结果直接当成工资金额。

## 工作流

1. 检查三类附件是否存在、可读且角色正确；保存文件名、页码/行号和解析警告。
2. 解析 `roster`，归一化姓名和项目名称；底表只用于补充人员信息和辅助匹配，不决定本次核算人员全集。
3. 解析 `historical_payroll`，按字段语义建立工资基准和月份公共规则；`基本工资`就是`岗位工资`，不得因为不存在“工资标准”字面列而判定基准缺失。历史“人工应发工资”只用于同月对比。
4. 对图片型 PDF 或图片考勤先调用 `vision_analyze`；PDF 由工具使用 worker 中已安装的 Python PyMuPDF 按页分段渲染为 PNG，再提交页面图片给当前 `vision=true` 模型。要求紧凑返回月份、项目、人员、实际出勤、周末/法定节假日实际出勤、`holiday_dates`、异常/休息/调换/加班日期、请假/旷工、离职/调动、未识别符号及页码/行号证据，不要为每人重复输出 1-31 日正常出勤符号。不要用文本读取工具代替视觉识别。
5. 解析 `attendance`，保留原始页/行证据，识别出勤、事假、病假、旷工、年假、调休和未识别符号。考勤无法识别或月份冲突时，才阻塞工资计算。
6. 以考勤和历史工资资料实际识别出的人员为主，按“姓名 + 项目 + 人员类别”匹配；同名或多候选不得强行匹配。
7. 基准缺失或工资构成不完整的人员进入 `review_exceptions`，按缺失分项处理，不阻塞其他人员；有完整或部分可用基准的人员继续计算已确认分项。
8. 未确认规则只跳过对应工资分项并写入复核说明，不阻塞该人员其他已确认分项的计算。
9. 逐项对比同月历史人工结果，生成差异字段、金额差异和一致性状态。
10. 必须生成核算明细、工资基准缺失清单、异常/复核清单和 Excel 结果；即使只有部分人员可计算，也不得只生成分析报告而不生成部分工资表。本场景不要求生成分析报告文件，分析结论在最终回复中简要说明即可。

## 确定性计算器

完成考勤识别后，必须调用 `scripts/payroll_calculator.py`，不得由模型直接心算或编造工资金额：

```bash
python scripts/payroll_calculator.py \
  --roster <人员底表.xlsx> \
  --historical <历史工资表1.xlsx> <历史工资表2.xlsx> \
  --attendance <vision输出的考勤.json> \
  --month 2026-06 \
  --output <项目工作目录>/2026年6月工资核算表.xlsx
```

基础工作日按当月天数减去周六日和不重叠的法定节假日计算；加班天数为实际出勤减基础工作日，按当月周末自然周数量封顶。vision_analyze 必须返回每人的 `actual_work_days` 和顶层 `holiday_dates`，不再要求周末出勤日期数组。
PDF 按原始页逐页识别，保持表格行和日期列的完整对齐；不再拆分人员行或左右日期列。

历史工资表可能没有项目和人员类别列，计算器会根据文件路径中的项目/用工类别补充匹配信息，并在无法唯一匹配时进入复核清单。计算器生成的工作簿必须经过 xlsx Skill 的重算和公式错误检查后，才能调用 `artifact_declare`。

## 固定计算边界

系统应发工资为税前金额：

`岗位工资 + 调整后绩效工资 + 工龄工资 + 职称工资 + 施工补贴 + 话费补贴 + 计入应发的高温补贴 + 交通补贴 + 加班费`

- 事假只扣绩效：`调整后绩效 = max(绩效标准 - 绩效标准 / 21.75 × 事假天数, 0)`；
- 通用加班日标准：`ROUND(岗位工资 / 21.75, 0) × 2`；
- 有特殊加班日标准时优先使用特殊标准；
- 可计薪加班天数：每个周六或周日实际出勤日期各计 1 天，同一周两天都出勤可计 2 天，最终封顶为当月周末自然周数量；不再要求用户选择工休制度；
- 超出计划的出勤只记为应休未休，不增加当月加班费；
- 有效年假和调休当前不扣工资；
- 高温补贴默认 6—9 月，是否计入应发以工资基准规则为准；
- 社保、公积金、个税、HR 公司扣款和最终实发不在范围内。

## 阻塞与人工复核

只有以下情况可以阻塞工资计算：

- 考勤文件无法读取或无法完成识别；
- 多份考勤资料的月份互相冲突；
- 完全没有任何可识别的考勤人员。

以下情况不得阻塞，必须部分计算并列入清单：

病假/旷工扣款、入离职分项折算、跨项目施工补贴分段、调休余额、正式高温政策、工龄晋档、机关偶发加班、同名无法唯一匹配或工资构成不完整时，不得猜测。只将对应分项列入复核清单，不得阻塞岗位工资、绩效、补贴等其他已确认分项。`换`表示已认可调休：该日不计工资、不计实际出勤，不列为未识别符号或人工复核事项。输出异常、证据和需要确认的问题。
